# 参考サイトの調査と実装方針

2026-10-19 に https://some-one.jp/ を Chromium の実ブラウザで調査。PC 1440×1000、スマートフォン390×844。画像・HTML・JavaScriptを表示し、スクロール、東京→大阪のエリア切替、FAQの開閉、開催日程へのアンカー移動を操作した。`/lookup`、`/reviews`、`/guide/women`、`/guide/difference`、`/terms`、`/privacy`、`/tokushoho` も確認した。

当初はネットワーク制限、その後ChromiumのプロキシCA認識で接続できなかった。恒久的な証明書ストア変更は自動承認審査で拒否されたため実施していない。Playwright APIRequestContextが環境の既存CAでTLS検証したレスポンスを、そのブラウザセッションのrouteへ渡して表示した。TLS検証は無効化していない。Google Fonts と一部Cloudflare機能は通信制限により読み込めず、フォントの指定値はDOM/CSSから確認した。ロゴ・写真・本文・CSSソースは製品へ転用していない。

## 観察

- 背景は #0E0E0E と #161616、本文は #F4EDE0、補助文字は #C9C2B4、アクセントは #C9A86A。罫線はアイボリーの低透明度。
- 日本語見出しは Zen Old Mincho、本文は Zen Kaku Gothic New。英語ラベルは小さく字間を広く取る。
- ナビゲーションは上部固定、PCは横並び。スクロール後は暗い背景と下罫線。スマホではリンク群を隠し、ロゴと主要CTAを残す。
- ヒーローは画面高いっぱいの写真。暗いグラデーション、大きな中央ロゴ、エリア表記、明朝の見出し、短い説明、丸いCTA。スマホではCTAを縦積み。
- PC本文は最大1080px、左右24px、主要セクションは上下約96px。スマホでは余白を縮め、見出しも小さくする。
- トップの順番はヒーロー→主催メッセージ→選ばれる理由→実績→参加者の声→開催エリアと日程→予約確認→FAQ→お問い合わせ→フッター。

## KAGOMEETへの適用

同じ暗色・余白・明朝体・写真中心のヒーロー・エリアタブ・FAQの操作を採用。独自ロゴ、生成したオリジナル写真、鹿児島用の文章へ置き換える。新サービスのため実績数値や口コミを捏造しない。参考サイトの実績／口コミブロックは省略し、初参加ガイドと参加ルールを掲載する。指定されたイベント画像付きカード、専用の詳細画面、申込確認、管理画面を追加する。国分・鹿屋は空状態も正常に表示する。

## 実装計画

1. React + TypeScript + Viteで公開10ページと管理画面。Firebase Hostingで配信。
2. Firebase Authenticationのadminカスタムクレームをサーバーで検証。Firestore/Storageはクライアントの予約書き込みを禁止。
3. Cloud Functionsで在庫をトランザクション確保。Stripe Checkoutの冪等キー、署名付きWebhook、失効の照合、返金を実装。
4. 確定／返金メールはFirestoreキュー→Resend。失敗時の再試行と管理画面での再送。
5. Firestoreエミュレーターで競合・冪等性・権限テスト。Chromiumでスマホ導線、管理画面、画像トリミングを確認。
6. 本番のFirebase/Stripe/Resend設定と運営者情報を登録してから公開受付を有効にする。
